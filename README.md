# PostCap
POS система для кав'ярень

## Структура проєкту
- `backend/` — Express API + Prisma (PostgreSQL)
- `frontend/` — React-застосунок: каса та адмін-панель
- `landing/` — статична сторінка-візитка продукту

## Можливості
- Каса з дворівневою навігацією категорій (плитки з іконками та кольоровими темами) та пошуком товарів
- Меню: категорії «Кава» (6 підкатегорій), «Чай» (5 підкатегорій), «Десерти» (4 підкатегорії), «Інше»
- Облік складу за рецептурою, фіскалізація чеків, звіти, керування змінами та працівниками
- Адмін-панель для власника кав'ярні

## Наповнення бази
Seed-скрипти в `backend/prisma/` (запускати вручну через `node prisma/<файл>.js`):
- `seed.js` — базові дані (категорії, інгредієнти, тестовий товар)
- `seed-coffee-categories.js`, `seed-coffee-products.js` — категорія «Кава» та її асортимент
- `seed-tea-other-categories.js` — категорії «Чай» та «Інше» з асортиментом
- `seed-dessert-subcategories.js` — підкатегорії «Десерти» (Торти, Випічка, Тістечка, Печиво) та їх асортимент
